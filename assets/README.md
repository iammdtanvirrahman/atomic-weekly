# Atomic Weekly — Magazine Media Library

Keep media that belongs to published articles, stories, magazine issues, and authors in this directory.

## Folders
- covers/ — article and story cover images
- science/ — physics, biology, chemistry, and other science article media
- technology/ — AI, robotics, computing, and engineering
- cosmos/ — astronomy, planets, stars, galaxies, and space exploration
- stories/ — fiction, romance, literary essays, and writer stories
- authors/ — author portraits and approved author profile images
- issues/ — issue covers and publication-specific artwork
- inline/ — diagrams, charts, infographics, and images used inside article bodies

## Current uploaded covers
- `issues/issue-01-cover.png` — first magazine issue cover
- `covers/science-feature-cover.png` — science feature cover
- `covers/technology-feature-cover.png` — technology feature cover
- `covers/stories-feature-cover.png` — stories feature cover

## Guidelines
- Use lowercase kebab-case filenames; make names descriptive, e.g. black-hole-accretion-disk.webp.
- Prefer WebP for photographs and illustrations; SVG for diagrams and simple vector art.
- Keep article-specific images here, not in web-assets/.
- The existing asset manager or publisher may expect some files directly under assets/. Keep any files currently referenced by published content in place unless all references are updated.
- Do not put secrets, API keys, tokens, or private user data in this directory.
